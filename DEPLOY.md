# Развёртывание food-preorder

## Что внутри

- публичный каталог с двумя поставщиками;
- корзина и форма предзаказа;
- защищённая админка;
- Cloudflare D1 для товаров и заявок;
- Cloudflare R2 для загружаемых фотографий.

## Требования

- Node.js 22.13 или новее;
- npm;
- Linux или WSL для штатных скриптов сборки.

## Локальный запуск

```bash
git clone https://github.com/rebuzik/food-preorder.git
cd food-preorder
npm ci
npm run dev
```

После запуска откройте адрес, который покажет Vite. Локальная среда использует эмуляцию Cloudflare D1 и R2. Если база создаётся впервые, примените SQL-файлы из каталога `drizzle/` по порядку.

## Проверка production-сборки

```bash
npm test
```

Команда собирает приложение, проверяет Sites-артефакт и запускает автоматический тест.

## Production

Проект рассчитан на Cloudflare Worker-совместимое окружение и требует два binding:

- `DB` — D1 database;
- `BUCKET` — R2 bucket.

Перед публикацией:

1. Создайте D1 database и R2 bucket.
2. Привяжите их к Worker под именами `DB` и `BUCKET`.
3. Примените миграции из `drizzle/` в порядке номеров.
4. Выполните `npm ci` и `npm run build`.
5. Разверните полученный Worker-артефакт из `dist/`.

Самый простой вариант — продолжать использовать уже созданный ChatGPT Sites-проект: он автоматически подключает D1, R2, миграции и защищённый вход в админку.

## Важное ограничение

Админка использует вход через ChatGPT Sites. При переносе на независимый Cloudflare Worker нужно заменить `app/chatgpt-auth.ts` на собственную авторизацию администратора либо настроить эквивалентную защиту маршрутов `/admin` и `/api/admin/*`.
